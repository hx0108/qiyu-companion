额外布局脚本仍验证 320px、375px、横屏、日夜、大字号、菜单滚动/焦点/关闭、通知与主动消息表单。真机中文输入法、权限拒绝、弱网/后台音频和声学质量需要独立验收，不能以桌面渲染替代。

测试浏览器使用专属临时进程；退出检测只检查本次 launchServer 返回的 PID，既不连接也不终止用户浏览器。所有断言完成及服务清理成功后 CLI 才正常结束；失败保持非零退出码。
