## 与确认样图一致的部分

- 402 × 874 CSS 逻辑像素的设计画布（对应 402pt × 874pt 产品设计尺寸），以及杏桃暖光背景。
- 欢迎页标题、原照片构图、底部文案与白色主按钮。
- 首页顶部人物区、标题、四张功能卡、圆角内容层、记忆横图与悬浮导航。
- 聊天页杏桃色顶部、白色圆角对话层、B3 文字语音一体气泡、记忆确认卡和底部输入条。
- 人物、阳台和回忆横图直接取自确认样图；底部四个图标按 `nav-icons-approved.png` 的轮廓使用专用矢量路径还原，其他操作图标仍使用 Lucide。
- 底栏四列等宽，图标在 64 × 40 的椭圆框内居中；只有选中图标显示杏桃底，标签独立排列。
- 底栏背景现为 402px 全宽贴边，内部保留 12px 安全留白；消除两侧露出的页面底色，不改变图标原有排列位置。
- 导航的原始批准素材保留为 `nav-icons-approved.png`。
- 首页四个功能图标使用 A2；文字语音回复使用最新版 B3：行内播放/暂停、朗读短句高亮、末尾时长，不设置独立语音条。
- A2、B3 的原始批准素材分别为 `a2-approved.png`、`b3-approved.png`；当前实现验收见根目录设计规范。
- 设置项、回忆列表及提示卡的装饰性尾部右箭头已移除，保留返回、发送、播放等功能性图标。

## 交互范围

欢迎与成年提示、角色创建、首页导航、文字对话、语音通话界面、图片与转写演示、记忆确认/修改/删除、约定提醒、人格版本、主动消息、数据导出与清空均可操作。

夜间模式覆盖首页、聊天、回忆、档案、首次使用表单、弹层、输入框和提示信息。主文字、次级文字、占位文字、图标与边界分别使用暗色语义配色，不复用浅色页面的固定颜色。

所有聊天、通话、图片和账户状态都是本地演示数据，不连接真实服务端；刷新页面恢复初始状态。

气泡中的播放/暂停和短句高亮是本地计时交互演示，不合成或播放真实语音；暂停续播、结束重播、切页暂停以及同时只播放一条均已实现。
