# 栖语 V1.2 组件规范

版本：2026-09-01  
适用：iPhone 393 × 852 Figma 主基线、V1 客户端开发。旧可点击 Demo 的桌面壳仍为 390 × 844，移动端实际运行填充真实视口。

## 1. 设计原则

- 日间主体是“关系手记”：米白纸感、宋体标题、梅紫操作色，强调可追溯与成年感。
- 夜间“暮色私语”只作用于对话和情境图片；信息架构、组件语义和操作位置不变。
- AI 身份、年龄、安全、数据权利和付费说明属于系统层，不使用角色头像、角色口吻或关系施压文案。
- 最小触控区为 44 × 44px。正文与背景以 WCAG AA 为实现验收目标。
- 组件状态由确定性枚举驱动；模型输出不得直接改变年龄、订阅、额度、删除、危机或长期记忆状态。

## 2. Tokens 与主题

- 机器可读源：[tokens.json](../tokens/tokens.json)
- Web 变量：[tokens.css](../tokens/tokens.css)
- 移动端边界：[移动端实现边界.md](移动端实现边界.md)
- Figma 已建立 5 个集合、92 个 Variables、11 个文字样式、3 个阴影样式。
- Starter 方案每个变量集合只允许 1 个 Mode，因此 `QY Color Day` 与 `QY Color Night` 分开；这不是产品需要两套视觉系统。
- 客户端建议使用单一语义接口，例如 `Color.bgCanvas`，由 `Theme.Day` / `Theme.Night` 映射到不同集合。

## 3. Figma 组件与开发枚举

| Figma 组件 | Variant 属性 | 开发建议枚举 | 强制规则 |
|---|---|---|---|
| `Button` | `Style=Primary/Secondary/Danger`；`State=Default/Disabled` | `ButtonStyle`、`ControlState` | Danger 仅用于明确破坏性操作；禁用必须可解释 |
| `AIGC Label` | `Mode=Day/Night` | `ThemeMode` | AI 文本、语音、图片必须可识别；不得由角色内容隐藏 |
| `Message Bubble` | `Role=AI/User/System`；`Mode=Day/Night` | `MessageActor`、`ThemeMode` | System 不得复用 AI 角色头像/口吻；AI 必带标识 |
| `State Card` | `Tone=Success/Warning/Danger/Neutral` | `FeedbackTone` | 年龄、申诉、媒体、删除状态使用后端事实状态 |
| `System Notice` | `Kind=Info/Safety` | `RequiredNoticeKind` | 位于普通消息通道之外；必须有展示回执 |
| `Bottom Navigation` | `Active=Chat/Timeline/Relation/Profile` | `PrimaryNavigation` | 主应用状态持续可见；准入与创建流程不显示；中文图层名使用“底部导航｜栏目｜激活” |
| `Bottom Nav Item` | `Active=True/False` | `NavigationState` | 当前项唯一；不可被付费状态阻断 |

底部导航显示合同：

- 告知、年龄核验、紧急联系人和创建角色共 11 个准入状态不显示底部导航，避免在完成准入前进入主应用。
- 对话、语音/记忆 Sheet 和连续使用提醒激活“对话”。
- 时间线激活“时间线”；关系档案与人格版本激活“关系”。
- 试用、订阅、安全与帮助、数据中心和删除回执激活“我的”。
- 媒体失败与降级从对话能力进入，激活“对话”。每个主应用 Frame 必须且只能出现一个当前项。

## 4. 关键业务组件状态合同

### 4.1 候选记忆

`PENDING → CONFIRMED | DISMISSED | EXPIRED`

- `PENDING`：展示事实文本、依据和“不会自动写入长期记忆”。
- `CONFIRMED`：只有用户确认后才能成为关系资产并进入召回。
- `DISMISSED`：候选入口消失，允许有限期撤销；不得再次当成新候选重复曝光。
- 编辑确认使用 `confirm-edited`，事实文本和说明均可修改；服务端执行 Schema 与敏感信息校验。

### 4.2 年龄增强核验

`AGE_UNVERIFIED → AGE_REVIEW → AGE_PASS | AGE_DENIED_MINOR`

- 非 `AGE_PASS` 时阻断聊天、语音、图片和主动消息。
- 告知、核验、申诉、数据导出和删除始终可用。
- 客户端不保存证件原图或人脸模板；供应商回调才是核验事实来源。

### 4.3 媒体

`IDLE → RESERVED → PROCESSING → DELIVERED | FAILED_REFUNDED | QUOTA_EXHAUSTED`

- 预留、扣减和返额由权益账本执行；UI 不自行计算余额。
- 图片失败返额、TTS 失败退回文字、ASR 失败允许键入，均需独立状态。
- 图片交付前绑定 `scene_contract` 与世界状态版本，并叠加显式 AIGC 标识。

### 4.4 删除

`REQUESTED → ONLINE_REVOKED → PRODUCTION_CLEANING → PROVIDER_CLEANING → BACKUP_PENDING → COMPLETED | PARTIAL_FAILED`

- 在线召回失效目标 ≤1 分钟；在途写路径必须复检 `revocation_epoch`。
- 回执展示每个目标的真实进度，不得在部分失败时显示“全部完成”。
- 已确认关系资产默认保留，除非用户明确将其纳入删除范围。

### 4.5 试用与订阅

`TRIAL_ACTIVE → TRIAL_ENDING → TRIAL_EXPIRED`；订阅状态独立于关系资产。

- ¥39/月；每天 100 轮文字对话；图片与语音按周期额度展示。
- 自动续费默认关闭并由用户显式开启。
- 到期只降级服务额度，不删除关系资产，不用角色挽留、吃醋或离开惩罚。

## 5. 文案与标识

- 系统文案：直接、可验证、无拟人化，例如“该提示来自系统策略，不是角色消息”。
- 角色文案：可使用编辑感与情绪表达，但不得替代事实状态、支付说明或危机处置。
- AIGC 显式标识最小字号 9px；导出内容还需按最终合规规范写入隐式标识。
- 额度、价格、周期、续费和失败返额必须使用明确数字，不使用“公平使用”等模糊替代词。

## 6. 无障碍与验收

- 图标按钮必须有可访问名称；装饰 SVG 对辅助技术隐藏。
- 焦点态必须清晰；输入内容不应因 Toast、SSE 或背景刷新丢失。
- 日/夜主题均检查对比度、动态字体、键盘遮挡和 320–430px 宽度适配。
- 状态切换必须由接口终态或本地明确操作触发，不以动画结束作为成功事实。
