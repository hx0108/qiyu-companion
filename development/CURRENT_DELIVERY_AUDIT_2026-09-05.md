## 本轮补齐

1. 新增显式 `QIYU_PRIVATE_MEDIA_STORE=tencent-cos` 开关。未设置时仍使用本机私有媒体库，避免因已有 COS 配置误将音频写云端。
2. 新增 COS 私有 TTS/ASR 对象存储：固定前缀、MIME/大小/对象键校验、无公开 URL、受鉴权的读取代理与删除状态。
3. 修复图片链路配置识别：单独配置 COS 媒体不会误启用混元/IMS 图片链路。
4. 受控真实冒烟：Qwen → TMS → 腾讯 TTS → COS 私有对象 → 鉴权读取 → 删除，结果均成功；测试媒体已删除。开发模拟支付仅用于授予测试额度，未发起真实收款。
5. PostgreSQL 开发存储现会加载并仅追加写入无正文的 `operation_metrics`；当前业务接线记录聊天生成、会话摘要、文本/图片审核、TTS/ASR 与混元图片调用的成功、阻断和失败；媒体等其他异步链路的重试指标、跨能力成本金额结算和实时告警仍待接入。
6. 新增 PRD 1.6 的 7 天完整体验档：必要告知与年龄准入后仅可领取一次，发放 3 张情境图和 5 分钟角色语音额度；不创建支付订单/回调，不自动续费，到期由服务端投影为 `EXPIRED` 并使媒体额度失效。试用账本来源仅允许 `TRIAL_GRANTED`，与已验证支付来源分开记录。
7. 会话摘要开发链路已接入：满 30 个已完成回合时，聊天事务同时写入带源边界与撤销纪元的摘要任务及无正文 Outbox 事件；本地开发 Worker 以独立、受限提示调用 Qwen 并可重试。摘要携带源消息 SHA-256 checksum、撤销纪元、模型/提示版本和不晚于源消息的留存截止时间。上下文仅接收校验仍有效的摘要与其边界后的最近消息；会话删除、账户注销和原始消息 TTL 均会先使命中摘要 `INVALIDATED`，再删除源消息；任务会取消而非写入过期数据。迁移 035/036/037 已持久化任务、专用 Worker 角色/租约和幂等 Outbox 请求事件；迁移 038 将达到 8 次失败的任务标记为耗尽并写入无正文 DLQ（仅任务/账户/会话标识、尝试次数和受控错误码），领取查询不再重试该任务；迁移 039 让专用 Worker 对追加式 `operation_metrics` 写入摘要生成成功/失败的供应商、模型版本、token 和延迟，不写对话或摘要正文。尚未提供自动重放、告警、成本金额结算或人工处置界面，也尚未在真实 PostgreSQL 与真实 Qwen 环境执行。其 `summary_ciphertext` 当前仍是开发期 UTF-8 占位写法，不能视为生产加密。

8. 新增 AI-04 固定记忆召回回归门禁：版本化合成集覆盖确认事实 Top-1、修订替换、删除资产零召回、账户/角色硬隔离；可由 npm run eval:memory-recall 生成可审计报告。当前集 3 条确认事实的 Top-1 错误为 0，删除与跨范围召回均为 0。此门禁只验证送入模型前的确定性候选，不等同于真实模型最终引用正确率、统计置信区间或真实 Bad Case。

9. 补齐会话摘要死信开发处置：开发 Worker 在第 8 次失败后停止领取、写入无正文 DLQ；内部审核员可查看无正文元数据，并在提供理由后仅重放一次。重放前重检账户、会话、撤销纪元与源消息；理由只保留 SHA-256，Outbox 只写任务标识和重放次数。迁移 040 为 PostgreSQL 定义独立摘要运营角色、受控函数和同一约束。当前尚未应用真实迁移，也没有独立运营台、真实告警或生产演练。
10. 第 7 项中“尚未提供自动重放、告警、成本金额结算或人工处置界面”是本次补齐前的历史描述；现已具备开发态单次受控重放与无正文内部处置接口，仍不具备生产告警、独立运营台、成本金额结算或真实 PostgreSQL 演练。
