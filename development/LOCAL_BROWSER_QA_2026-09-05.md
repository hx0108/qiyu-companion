# 本地浏览器验收记录（2026-09-05）

> 环境：`http://127.0.0.1:3110`，内存开发 Store、合成开发账户、Mock 回复生成器；未启用 Qwen、腾讯云、支付或年龄供应商。此记录是本地人工浏览器验收，不替代稳定的自动化浏览器 E2E，也不构成生产验收。

| 路径/状态 | 实测结果 | 证据边界 |
|---|---|---|
| 必要告知 → 年龄声明 | 未勾选告知时继续按钮禁用；提交回执后进入年龄页；提交合成年龄日期后进入角色创建页 | 仅验证服务端开发状态机，不验证真实年龄断言。 |
| 角色创建 → 对话 | 选择内置合成模板、确认原创/授权后进入对话页 | 不涉及真实人物或第三方 IP。 |
| 对话 SSE 回放 | 首条消息暴露前端重复拼接 `/api/v1` 的 404；修复后第二条合成消息完整回放，浏览器错误控制台为 0 | 仅使用 Mock 回复，不验证真实模型流式能力。 |
| TTS 未启用降级 | 点击“生成角色语音”后，文字消息保留，页面显示“角色语音未生成”与 `TTS_NOT_ENABLED`；浏览器记录预期的 503 能力未启用响应 | 只验证本地关闭 TTS 时的 UI 降级；不等同于腾讯 TTS 成功、失败或配额的真实调用。 |
| 日夜主题 | 对话页主题切换控件可触发重新渲染 | 主题是客户端渲染状态。 |
| 安全中心 → 数据中心 | 固定安全入口可达；数据中心从 90 天切换为 30 天，页面按 API 回读显示 | 不验证真实紧急联络、生产删除、备份或供应商回执。 |

## 修复

后端的 `stream_url` 已是 `/api/v1/...` API 相对路径；前端曾再次前缀 `API_BASE`，形成 `/api/v1/api/v1/...`。现在只对不带 API 前缀的调用补前缀。开发壳测试会阻止旧的重复拼接模式回归。

## 后续

把本次人工路径转为稳定浏览器自动化：告知/年龄、角色创建、对话 SSE、数据中心、时间线、安全中心以及媒体失败视图。外部供应商、支付、年龄核验和生产删除保持单独环境验收。
