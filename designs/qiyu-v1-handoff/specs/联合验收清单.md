# 栖语 V1.2 UI、产品、开发联合验收清单

本清单用于会议走查和签字，不等同于当前已通过。每项需记录负责人、日期、证据链接和结论。

## A. 完整闭环

- [ ] AI 身份与数据告知三项未全选时不可继续，展示回执可审计。
- [ ] 年龄 `PASS/REVIEW/DENIED` 和申诉均可走通；非 PASS 状态阻断聊天/语音/图片，但不阻断数据权利。
- [ ] 角色创建包含原创/授权确认、固定音色和参考图风险审查状态。
- [ ] 文字、异步语音、情境图片均携带 AIGC 标识；语音转写经用户确认后才发送。
- [ ] 候选记忆支持确认、修改事实、拒绝；拒绝后不复活。
- [ ] 时间线只展示有效关系资产；世界状态修改/重置影响后续情境图合同。
- [ ] 试用进行中、即将到期、到期降级和 ¥39 订阅闭环文案一致。
- [ ] 安全中心、2 小时提醒、R2 响应、举报/投诉入口稳定且不被角色覆盖。
- [ ] 数据留存、导出、删除范围、1 分钟在线失效和删除回执可见。

## B. 状态与接口

- [ ] 42 个状态在静态展开版、V1.2 深链清单和对照表中 ID 一致。
- [ ] 所有成功态有服务端终态来源；错误、超时、重试、幂等和断网恢复已定义。
- [ ] `AGE_PASS`、额度、订阅、记忆确认、删除完成、R2 等关键状态不由模型或客户端自报。
- [ ] 人格版本历史接口缺口已冻结方案，不允许开发临时拼接内部接口。
- [ ] `revocation_epoch` 在助手消息持久化和媒体交付写路径复检。

## C. 视觉与无障碍

- [ ] iPhone 393 × 852 主基线完成；320、375、430px 和键盘弹起状态无截断。
- [ ] 日间“关系手记”和夜间“暮色私语”语义一致，切换不改变信息架构。
- [ ] 最小触控区 44px；焦点态、屏幕阅读器名称、动态字体已验证。
- [ ] 日/夜主题正文和关键操作达到 WCAG AA 对比度目标。
- [ ] Toast、SSE、倒计时或媒体轮询不会清空输入框或抢夺焦点。

## D. 隐私、安全与商业

- [ ] 埋点/日志不含完整私聊、证件、人脸、原始音频和紧急联系人明文。
- [ ] AIGC 显式/隐式标识方案经法务与客户端实现共同确认。
- [ ] 自动续费默认关闭；取消 ≤2 步；恢复购买、宽限期、退款追回状态已联调。
- [ ] 停止订阅不删除关系资产；不存在吃醋召回、离开惩罚或亲密度付费。
- [ ] 删除回执与供应商实际清理结果可对账；部分失败不会显示全部完成。
